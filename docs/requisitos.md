# Requisitos Funcionais

# RF01 - Inserir números
# Descrição: O sistema deve permitir que o usuário insira dois números para realizar os cálculos.
# Critério de aceitação: O sistema deve aceitar números inteiros e decimais digitados pelo usuário.

# RF02 - Selecionar operação matemática
# Descrição: O sistema deve permitir que o usuário escolha uma operação matemática básica.
# Critério de aceitação: O sistema deve reconhecer corretamente os operadores válidos.

# RF03 - Realizar soma
# Descrição: O sistema deve realizar a soma entre dois números informados pelo usuário.
# Critério de aceitação: O sistema deve exibir corretamente o resultado da operação de adição.

# RF04 - Realizar subtração
# Descrição: O sistema deve realizar a subtração entre dois números.
# Critério de aceitação: O sistema deve apresentar corretamente o resultado da operação.

# RF05 - Realizar multiplicação
# Descrição: O sistema deve realizar a multiplicação entre dois números.
# Critério de aceitação: O sistema deve calcular corretamente o resultado da multiplicação.

# RF06 - Realizar divisão
# Descrição: O sistema deve realizar a divisão entre dois números.
# Critério de aceitação: O sistema deve impedir divisões por zero e exibir mensagem de erro apropriada.

# RF07 - Exibir resultado
# Descrição: O sistema deve mostrar ao usuário o resultado da operação realizada.
# Critério de aceitação: O resultado deve ser exibido de forma clara e legível.

# RF08 - Permitir novos cálculos
# Descrição: O sistema deve permitir que o usuário realize novos cálculos sem reiniciar o programa.
# Critério de aceitação: O sistema deve continuar funcionando até que o usuário escolha sair.

# RF09 – Validar entradas inválidas
# Descrição: O sistema deve validar os dados digitados pelo usuário.
# Critério de aceitação: O sistema deve impedir letras ou símbolos inválidos nos campos numéricos.


# Requisitos não funcionais

# RNF01 – Facilidade de uso
# Descrição: O sistema deve possuir interface simples e de fácil entendimento no terminal.
# Critério de aceitação: Usuários devem conseguir utilizar o sistema sem necessidade de treinamento.

# RNF02 – Desempenho
# Descrição: O sistema deve apresentar o resultado das operações rapidamente.
# Critério de aceitação: Os cálculos devem ser processados em menos de 1 segundo.

# RNF03 – Compatibilidade
# Descrição: O sistema deve funcionar em computadores que possuam Python instalado.
# Critério de aceitação: O programa deve executar corretamente em ambientes Windows, Linux e macOS.

# RNF04 – Tratamento de erros
# Descrição: O sistema deve tratar entradas inválidas sem encerrar inesperadamente.
# Critério de aceitação: O programa deve continuar funcionando após erros de digitação do usuário.
